8.1 · The Clockwork Maze

Integers laid out around a clock. Each position x is coloured by the value of f(x)=ax mod N. Because modular exponentiation is periodic, the colour pattern repeats every r steps — the period that Shor's algorithm is built to find.

f(x) = ax mod N
gcd(a,N)=1 · period r = 4

The Clockwork Ring

colour = residue value 0…N−1 one full turn = 3 periods

Unrolled Sequence — period brackets

period r = 4 ar mod N = 1

How to read it. Walk clockwise from x = 0. The colours march through a fixed cycle and then snap back — every r positions you return to the same colour, so the ring shows perfect rotational symmetry and the strip shows identical coloured blocks. That hidden period r is what a quantum computer extracts in one shot via the QFT (see 8.2 & 8.3).
Try a=7, N=15 (r=4), a=2, N=15 (r=4), a=2, N=21 (r=6), a=5, N=21 (r=6). If gcd(a,N)≠1 the walk never returns to 1 — but that shared factor already cracks N.

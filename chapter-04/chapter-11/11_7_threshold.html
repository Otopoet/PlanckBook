Surface code & the threshold

A quantum error-correcting code only helps below a critical physical error rate — the threshold, here about 1%. Below it, adding physical qubits (larger code distance d) suppresses the logical error rate exponentially. Above it, encoding actively makes things worse: more qubits, more error. Drag the slider to move the physical error rate across the threshold and watch each code respond.

Fighting back: the repetition code

The gentlest first step in quantum error correction. We protect one logical bit by smearing it across three physical qubits — 0 → 000, 1 → 111. Noise flips each physical qubit on its own; a majority vote reads the answer back out. The catch: redundancy only helps below a threshold error rate. Above it, more qubits just means more ways to fail.

Physical error rate

Each of the three physical qubits flips independently with probability p. This single dial drives every panel below.

Break-even curve

The encoded curve PL(p) versus the do-nothing line y = p. They cross exactly at p = 0.5 — the break-even point of the 3-qubit code.

encoded PL(p) = 3p²−2p³ unencoded y = p break-even at p = 0.5
Detect & correct. If a single qubit flips it becomes the odd-one-out — the syndrome — and the majority of two still points the right way, so one error is silently corrected. A logical error only happens when two or three flip and the majority swings the wrong way.
Below break-even the code suppresses errors; above it, it amplifies them. For p < 0.5 the cyan curve sits under the dashed line — encoding wins. For p > 0.5 it rises above — three noisy qubits are worse than one.
Why bother? Bigger codes — more physical qubits, and ultimately the 2-D surface code (Figures 11.7 & 11.8) — push the threshold higher and, once you are below it, drive the logical error rate down exponentially as you add qubits. The 3-qubit repetition code is just the seed of that idea.
